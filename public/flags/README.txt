Drapeaux SVG (format 4x3) de la bibliothèque flag-icons 7.2.3 (https://github.com/lipis/flag-icons), licence MIT (LICENSE.txt).
Optimisés avec svgo (précision 1 décimale) ; un fichier par code ISO des pays présents dans les données (Marie-Galante : gp, Tobago : tt).
Utilisés en filigrane (5 % d'opacité) sur la bande « Coming up » de l'accueil. Hébergés ici, jamais chargés depuis un CDN (CSP font-src/img-src 'self').
Choix de drapeau par territoire : ceux de flag-icons (Guadeloupe, Guyane, Saint-Martin et Saint-Barthélemy : drapeau français ; Martinique : drapeau rouge-vert-noir).
